## 排期使用说明

- “预期天数”是开发估算，不包含临时需求变更、跨团队等待和正式发布审核时间。
- P0 建议先完成主计分、发球、暂停、胜负判定和继续比赛，再接入车轮赛。
- P1 依赖 P0 的比赛数据结构，历史记录和配置功能应复用同一套比赛模型。
- P2 的双打和团队赛建议在单打计分核心稳定后开发，避免重复实现计分与结果判定逻辑。
- 截止时间暂不填写，待确定项目启动日期、开发人数和迭代周期后统一补充。
