# PingScore 赛事控制台 UI 规范

## 目标

将 PingScore 统一为明亮、克制、比赛优先的“赛事控制台”界面。比分应是每个屏幕的第一视觉焦点；红、蓝、绿和深色只承担明确的语义，不再同时作为装饰色竞争注意力。

本轮是视觉与布局重构，不修改 `MatchEngine` 的计分、赛制、暂停、车轮赛、双打和团队赛规则。

## 视觉令牌

| 语义 | 颜色 | 用途 |
| --- | --- | --- |
| 页面底色 | `#F4F7FA` | 主界面背景 |
| 表面 | `#FFFFFF` | 状态条、比分卡、表单卡、弹窗 |
| 柔和表面 | `#EEF3F7` | 次级区域、禁用状态 |
| 主文字 | `#17212B` | 标题、比分、重要正文 |
| 次级文字 | `#6F7B87` | 说明、待赛、次要标签 |
| 分隔线 | `#D5DEE6` | 卡片边框、区域分隔 |
| 玩家 1 | `#EB565D` | 玩家 1 加分、比分卡色条、结果强调 |
| 玩家 2 | `#2675D8` | 玩家 2 加分、当前小局、主要确认 |
| 发球 | `#1FAC71` | 当前发球、换发、可恢复状态 |
| 设定 | `#1B2732` | 设定和全局设置 |
| 暂停 | `#D94D55` | 暂停和锁定状态 |

- 所有实体按钮、卡片和列表项采用 `8dp` 圆角。
- 普通容器采用 `1dp` 分隔线；比分卡不用粗黑描边。
- 主页面横向页边距为 `16dp`，相邻控件固定使用 `8dp` 或 `12dp`，不再贴边堆叠。
- 字号层级：页面标题 `24sp`，玩家名 `20sp`，主比分 `64sp-88sp`，主要操作 `20sp`，状态信息 `13sp-15sp`。
- 禁用控件保持位置，但降为柔和表面和约 `48%` 透明度，不以隐藏造成布局跳动。

## 主计分

### 竖屏

1. 顶栏为历史、居中标题、全局设置，三者均使用相同 `44dp` 触控框。
2. 顶栏下方采用一条白色比赛状态条：左侧显示比赛状态，右侧显示模式、BO、当前局和大比分。
3. 小局使用横向 RecyclerView，已完成、当前、待赛三种状态保持同一尺寸；当前局仅使用蓝色边框与浅蓝底，不使用绿色。
4. 两位玩家各占一半空间。名字和发球状态位于卡片上方；比分卡仅有对应玩家的细色条和中性边框。
5. `+1` 是该玩家唯一高饱和主操作；`-1` 使用白底描边，降低误触后的视觉权重。
6. 底部三个操作保持“设定 / 暂停 / 换发”的职责与顺序，独立按钮之间有固定间距，不再置于抢眼的蓝色底板上。
7. 查看已完成小局时，隐藏加减分并居中展示“赛果调整”，比分卡仍保留双方颜色提示。

### 横屏

1. 左侧为 `224dp` 左右的控制栏，使用白色表面和细边框，与右侧比分舞台通过 `16dp` 间距分离。
2. 控制栏从上到下为：历史/标题/设置、比赛状态、小局列表、模式辅助入口、设定/暂停/换发。
3. 右侧只承载比分与暂停状态，不复制左侧的导航或底部操作栏。
4. 横屏比分卡的字号应大于竖屏，仍保留最小 `12dp` 外边距和稳定的操作按钮高度。

## 状态与弹窗

- 暂停锁定使用浅红状态条和白色弹窗，倒计时以红色为单一强强调；不可编辑项降调但不与可点击项混淆。
- 发球选择、暂停方选择、团队待赛添加都使用白色选择卡，已选项用蓝色细边框，发球者状态只用绿色徽标。
- 本场设定、全局设置和历史记录使用同一弹窗框架：标题、可滚动内容区、底部操作区。
- 表单的选手、队伍、预设等可新增项目采用完整的白色输入行和删除动作，不出现裸露的单行输入框。
- 比赛结束页将获胜方用玩家对应色强调，落败方使用次级灰；每局赛果为可扫读的独立行。
- 历史记录采用比赛摘要卡列表，详情页使用模式标签和小局结果列表，而不是系统默认 ListView 文本列表。

## 不变量

- 保留所有现有 View ID，或在 Java 中同步更新引用，确保 P0/P1/P2 行为不回退。
- 红色固定代表玩家 1 加分，蓝色固定代表玩家 2 加分，绿色固定代表当前发球或换发。
- 紫色不进入主计分、设置或弹窗配色。
- 竖屏和横屏均覆盖 BO1、BO3、BO5、BO7 的小局数量，并允许 RecyclerView 滚动。
- 所有可点击目标不低于 `44dp`，不以仅图标的小目标替代主要比赛操作。
