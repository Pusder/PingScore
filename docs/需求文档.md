## 1. 产品概述

### 1.1 产品定位

乒乓球计分器 APP 面向乒乓球爱好者、业余比赛组织者和训练场景，解决传统计分易出错、规则记忆繁琐的问题，提供：

- 符合正规比赛规则的数字化计分
- 灵活的娱乐赛制配置
- 发球权、局分、暂停和比赛结果管理
- 车轮赛、双打和团队赛支持
- 比赛历史记录和详细小局复盘

### 1.2 目标用户

- **乒乓球爱好者**：日常约球和娱乐赛，需要快速记录比分。
- **业余比赛组织者**：社区赛、公司赛，需要规范计分和多种赛制。
- **专业训练场景**：教练或陪练，需要精确记录局分和暂停情况。

## 2. 核心功能需求

### 2.1 主计分界面

主界面是单手操作的核心区域，需要保证高对比度、远距离可读和触控热区合理。

- **布局**：左右分别显示两位玩家或两支队伍的计分区域；顶部显示当前局数；底部提供“设定”“暂停”“换发”。
- **赛制扩展**：主界面必须兼容 BO1、BO3、BO5、BO7 四种比赛长度，局数、局分状态和比赛进度根据当前赛制动态生成，不能将页面固定为某一种 BO 赛制。
- **局数适配**：BO1 显示单局决胜；BO3 显示最多 3 局；BO5 显示最多 5 局；BO7 显示最多 7 局。已完成的小局以比分胶囊或列表展示，未开始的小局显示待赛状态。
- **赛制显示**：主界面必须明确显示当前赛制，例如“BO3 · 第 2 局 / 3 局”或“BO7 · 第 4 局 / 7 局”。
- **玩家名称**：支持点击编辑，默认显示“玩家 1”和“玩家 2”。
- **发球标识**：高亮当前发球方，并显示接发状态。
- **比分显示**：使用超大字号显示当前局比分。
- **加减分控件**：每位玩家独立提供 `+1` 和 `-1` 大按钮，避免误触对方分数。
- **历史记录**：左上角进入全部比赛记录。
- **全局设置**：右上角齿轮进入撤销提示、声音、震动等全局设置。
- **横竖屏**：支持竖屏和横屏布局，横屏用于桌边远距离查看。

### 2.2 赛制与本场设定

主计分页底部“设定”进入本场比赛设置；右上角齿轮进入全局设置。页面按比赛类型使用选项卡组织。

| 配置项 | 功能描述 | 默认值 / 规则 |
| --- | --- | --- |
| 正规模式赛制 | 支持 BO3、BO5、BO7；BO3 即三局两胜，以此类推 | 默认 BO3 |
| 娱乐模式赛制 | 支持 BO1、BO3、BO5、BO7 | 默认 BO3，可自由切换 |
| 单局分数 | 设置单局获胜所需分数 | 正规模式固定 11 分；娱乐模式可选 11 分或 21 分 |
| 发球规则 | 正规模式每 2 分换发，10:10 后每 1 分换发；娱乐模式可自定义 | 娱乐模式可选每 1 分、每 2 分、每 5 分 |
| 车轮赛 | 创建多个选手，任意选择两人 PK，不限制顺序和比赛场次 | 默认 BO1、11 分制 |
| 双打模式 | 两队各 2 名选手，支持双打发球、接发和击球顺序 | 正规双打规则 |
| 团队赛 | 多支队伍进行多场单打或双打，按小场胜场累计团队比分 | 至少 2 队，每队 2-6 人 |
| 暂停规则 | 每位选手或组合每场 1 次暂停，时长 1 分钟 | 默认开启 |
| 预设配置 | 快速切换正规、娱乐、车轮赛、双打和团队赛 | - |
| 自定义保存 | 将当前参数保存为个人配置 | - |
| 重置比赛 | 清空当前比分，保留配置，并进行二次确认 | - |

> 说明：主计分界面统一按 BO1 / BO3 / BO5 / BO7 的最大兼容范围设计；赛制设置决定当前比赛实际使用的 BO 类型。正规模式当前可选 BO3 / BO5 / BO7，娱乐模式可选 BO1 / BO3 / BO5 / BO7，车轮赛默认 BO1。

### 2.3 发球管理

- **自动切换**：非平分阶段每累计 2 分换发；10:10 后每累计 1 分换发。
- **手动干预**：点击“换发”弹出发球选择 Sheet，手动指定当前发球方。
- **视觉反馈**：当前发球方使用高亮标识，接发方使用弱化标识。
- **双打扩展**：双打模式按照发球者、接发者和搭档的固定轮转顺序管理，不能只切换队伍。

### 2.4 暂停管理

- **触发机制**：点击主计分页底部“暂停”，先弹出选择暂停方窗口。
- **选择弹窗**：左右展示两位玩家、当前局比分和暂停剩余小点；实心点表示已使用，空心点表示可用。
- **状态锁定**：暂停期间锁定加减分、换发和设定操作。
- **次数限制**：每位玩家或组合每场仅 1 次暂停，使用后显示已用状态。
- **恢复机制**：倒计时结束或点击“提前结束暂停”后恢复计分操作。

### 2.5 比赛结果

- **单局判定**：达到当前单局分数且领先 2 分，判定该局获胜。
- **全场判定**：
  - BO3：先胜 2 局
  - BO5：先胜 3 局
  - BO7：先胜 4 局
- **结果展示**：展示最终大比分、每局小比分和每局获胜方。
- **颜色规则**：最终胜方使用红色，落败方使用灰色或淡黄色；每局获胜方使用对应颜色。
- **后续操作**：提供“再来一场”和“重新开始”。

### 2.6 车轮赛

- 可创建多个临时选手。
- 任意选择两名选手进行 PK。
- 默认 BO1、11 分制。
- 不要求固定轮换顺序。
- 不限制每位选手必须参加的场次。
- 历史记录按每一场 PK 单独展示。

### 2.7 双打模式

- 两队各 2 名选手，比分按队伍累计。
- 每局开始确认首发球员和首位接发球员。
- 每次换发后，上一回合接发者成为发球者，上一回合发球者的搭档成为接发者。
- 发球后双方队员按固定顺序交替击球。
- 决胜局先有一方达到 5 分时交换场地，并按规则调整接发顺序。
- 规则说明在双打页面外部文本区集中展示。

### 2.8 团队赛

- 支持创建多支队伍，每队 2-6 名选手。
- 每场团队赛可包含多场单打或双打。
- 每场小场结束后累计团队胜场。
- 先达到目标胜场的队伍获胜。
- 主计分页显示当前小场、团队总比分和下一场对阵。

## 4. 页面结构与交互流程

页面通过选项卡分组展示，同一类型页面不在线性页面中全部展开。宽屏一行最多展示两个页面，窄屏自动单列。

1. **主计分**：打开 APP 默认进入；展示比分、局数、发球方和高频操作。
2. **赛制与设置**：配置本场规则和全局偏好。
3. **发球选择**：点击“换发”打开底部 Sheet，选择当前发球方。
4. **选择暂停方**：点击“暂停”打开左右布局弹窗，选择玩家后进入锁定状态。
5. **继续比赛**：检测到未结束比赛时，可恢复比分、局数、发球方和暂停状态。
6. **比赛结束**：显示大比分、每局比分和获胜方，并提供后续操作。
7. **历史记录**：展示全部比赛；普通/娱乐比赛按小局展示，车轮赛按每场 PK 展示，团队赛按小场展示。
8. **双打**：展示两队选手、发球方、接发方和固定击球顺序。
9. **团队赛**：展示队伍、队员、小场对阵、团队总比分和下一场安排。

## 5. 非功能性需求

### 5.1 交互体验

- 加减分按钮触控热区不小于 48 x 48 dp。
- 支持单手拇指操作。
- 界面响应时间小于 100 ms，确保连按不丢分。
- 任何 `+1` 或 `-1` 后显示可撤销提示，撤销入口属于全局设置项。

### 5.2 视觉适配

- 同时支持横屏和竖屏。
- 使用高对比度配色，确保球馆强光或暗光环境下清晰可见。
- 宽屏页面最多两列，窄屏页面自动单列。

### 5.3 感知反馈

- 声音反馈需在嘈杂环境（大于 80 dB）下可辨识。
- 震动反馈需有明确触感，并区别于系统通知震动。

## 6. 技术约束与规范

- **包名**：`com.comm.pingscore`
- **开发框架**：Android 原生 Kotlin/Java 或 Flutter，由技术团队根据现有架构决定。
- **用户配置**：使用 SharedPreferences 或 Room/SQLite 存储。
- **比赛过程数据**：建议持久化未结束比赛，以支持“继续比赛”；已完成比赛写入历史记录。
- **冷启动时间**：小于 1.5 秒。
- **内存占用**：小于 100 MB。

## 8. 赛事控制台 UI 规范

### 8.1 颜色与形态

- 页面使用浅灰蓝背景与白色内容面，常规边框为 1dp，圆角统一为 8dp。
- 玩家 1 使用红色，玩家 2 使用蓝色，当前发球使用绿色；本场设定使用深色，暂停使用红色。
- 比分卡仅保留顶部语义色条与细边框，不使用粗黑外框；加分、减分和赛事控制均保持稳定尺寸。

### 8.2 竖屏主计分

- 外侧保留 16dp 页边距，信息顺序为：顶部导航、比赛状态、小局页签、双方比分、大按钮与赛事控制。
- 小局页签需随 BO3 / BO5 / BO7 动态扩展；已完成小局进入赛果查看状态时隐藏加减分，仅显示赛果调整入口。
- 玩家信息、发球状态和比分使用红蓝语义卡片；底部固定为深色设定、红色暂停、绿色换发三个操作。

### 8.3 横屏主计分

- 左侧使用独立控制栏，按顺序容纳赛事状态、可滚动小局页签、设定、暂停与换发；右侧保留独立的大比分舞台。
- 在 360dp 高的手机横屏中，三项赛事操作与至少一个小局页签必须同时可见，不允许被系统导航区裁切。
- 宽屏不将设定、暂停、换发与双方比分混排在同一横向信息流中。

### 8.4 动态弹窗与记录

- 本场设定、全局设置、团队对阵等输入均使用有边框的卡片行；下拉选择必须带展开指示。
- 换发和暂停选择使用双方卡片，展示本局比分、总比分和暂停可用状态；暂停锁定展示动态倒计时与提前结束操作。
- 比赛结束需区分胜方红色与落败方灰色；历史记录以可点击卡片展示，并按普通/娱乐、车轮、双打、团队赛使用对应摘要与详情布局。

### 8.5 UI 验收

- 竖屏、横屏、设定、换发、暂停与空历史状态均无文字重叠、控件裁切或系统默认控件突兀混入。
- 所有动态表单、赛果摘要和历史小局标签由统一的 UI 样式层生成，避免模式之间出现颜色与间距漂移。
